# Curl based Content discovery scanner

A teeny tiny dirbuster scanner.



## Features

- Fast URL/path enumeration using `curl`
- Supports wordlist based scanning
- Optional file extension brute forcing
- HTTP status code detection
- Lightweight and dependency-free (uses system `curl`)
- Simple CLI interface





## Disclaimer

This tool is intended for **educational and authorized security testing only**.

Do not use it against systems you do not own or have explicit permission to test.
